# Portafolio profesional

Sitio personal de Enrique Morales, publicado con GitHub Pages en
[enriquemorales2010.github.io](https://enriquemorales2010.github.io/).
Muestra su perfil profesional combinado en BI, análisis de datos y
Power Platform.

## Contenido del sitio
- Navegación fija con acceso rápido a cada sección y modo claro/oscuro
- Hero con métricas clave estilo panel de control (años de experiencia, % de mejora, etc.)
- Habilidades agrupadas en tarjetas (Datos y BI, Power Platform, Cloud, otras herramientas)
- Experiencia laboral completa
- Educación y certificaciones
- Proyectos destacados
- Galería de dashboards de Power BI con vista ampliada (lightbox)
- Idiomas
- Contacto y descarga de CV en PDF (según el cargo: Analista de Datos/BI o Power Platform Developer)

## Archivos
- `index.html` / `styles.css` / `script.js`: sitio publicado (modo oscuro, menú móvil y lightbox de galería).
- `assets/img/powerbi/`: capturas de dashboards de Power BI mostradas en la galería. Los nombres de clientes y personas se difuminan antes de subir cualquier captura nueva.
- `cv-enrique-morales-analista-datos-bi.pdf`: CV enfocado en Analista de Datos / BI.
- `cv-enrique-morales-power-platform-developer.pdf`: CV enfocado en Power Platform Developer.

## Objetivo
Publicar una web simple, clara y profesional para que sirva como carta de presentación online.
