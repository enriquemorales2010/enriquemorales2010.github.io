# Portafolio profesional

Este proyecto contiene la web personal de Enrique Morales, orientada a mostrar su perfil profesional en BI, análisis de datos, Power Platform y automatización de procesos.

## Contenido del sitio
- Presentación profesional
- Habilidades principales
- Experiencia destacada
- Proyectos destacados
- Información de contacto

## Objetivo
Publicar una web simple, clara y profesional para que sirva como carta de presentación online.
