[enriquemorales2010.github.io](https://enriquemorales2010.github.io/).
Muestra su perfil profesional combinado en BI, análisis de datos y
Power Platform.

## Contenido del sitio
- Presentación profesional
- Habilidades (Datos y BI, Power Platform, Cloud, otras herramientas)
- Experiencia laboral completa
- Educación y certificaciones
- Proyectos destacados
- Idiomas
- Contacto y descarga de CV en PDF (según el cargo: Analista de Datos/BI o Power Platform Developer)

## Archivos

- `cv-enrique-morales-analista-datos-bi.pdf`: CV enfocado en Analista de Datos / BI.
